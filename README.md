# Кабинет мастера

Сайт лежит в корне репозитория, без папок.

## Страницы
- `index.html` — прайс и смета для заказчиков, правка прайса.
- `calc.html` — кабинет мастера (калькулятор, объекты, история, замер).
- `view.html` — счёт для заказчика по ссылке.

## Части кабинета мастера (`calc.html`)
- `calc.css` — оформление.
- `calc-app.js` — основа: вход, калькулятор, счета, история, объекты, PDF.
- `calc-measure.js` — замер и расчёты (стены, проёмы, откосы, потолок).
- `calc-rooms.js` — помещения объекта и выбор работ.
- `calc-ruler.js` — рулетка, чертёж, развёртки стен, окна и двери.
- `calc-molding.js` — лепнина: карнизы, плинтус, молдинги на потолке и стенах.
- `calc-tile.js` — плитка: на стенах и на полу, размер, шов, раскладка, запас, упаковки.
- `calc-mask.js` — укрывка: окна, двери, мебель, пол, потолок, готовые стены; теневые профили; периметр примыкания без двойного счёта общих участков, в счёт по видам; план и развёртки.
- `calc-plan.js` — обмерный план в PDF.
- `calc-import.js` — подложка и распознавание плана.
- `calc-assistant.js` — «Помощник по счёту»: чат с нейросетью (через воркер, ключ ANTHROPIC_API_KEY), подбирает работы из прайса, объём по поверхностям считает калькулятор.
- `calc-paid.js` — платные функции (распознавание и помощник) с баланса мастера в рублях: запрос на пополнение, у админа — зачисление, цены за токены, расход.
- `calc-aichats.js` — история чатов помощника и распознавания плана (хранится в браузере, IndexedDB).
- `calc-extras.js` — оповещение «Сайт обновлён» и мелочи.

**Важно:** при обновлении любой части заливайте вместе с ней и `calc.html` —
в нём стоят метки версий частей, по ним телефоны понимают, что пора обновиться.

## Остальное
- `sw.js`, `manifest.json`, `icon-*.png` — установка как приложения.
- `worker.js`, `wrangler.toml` — сервер на Cloudflare (деплой через wrangler).

## Проверки
- `tests/` — автопроверки расчётов замера (площади, чертёж, подправка плана, подиумы и короба) и помощника.
  Запуск из корня: `node --test`. На GitHub они идут сами при каждом PR.
