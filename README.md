# Кабинет мастера

Сайт лежит в корне репозитория, без папок.

## Страницы
- `index.html` — прайс и смета для заказчиков, правка прайса.
- `calc.html` — кабинет мастера (калькулятор, объекты, история, замер).
- `view.html` — счёт для заказчика по ссылке.

## Части кабинета мастера (`calc.html`)
- `calc.css` — оформление.
- `calc-app.js` — основа: вход, калькулятор, счета, история, объекты, PDF.
- `calc-measure.js` — замер и расчёты (стены, проёмы, откосы, потолок).
- `calc-rooms.js` — помещения объекта и выбор работ.
- `calc-ruler.js` — рулетка, чертёж, развёртки стен, окна и двери.
- `calc-plan.js` — обмерный план в PDF.
- `calc-import.js` — подложка и распознавание плана.
- `calc-extras.js` — оповещение «Сайт обновлён» и мелочи.

**Важно:** при обновлении любой части заливайте вместе с ней и `calc.html` —
в нём стоят метки версий частей, по ним телефоны понимают, что пора обновиться.

## Остальное
- `sw.js`, `manifest.json`, `icon-*.png` — установка как приложения.
- `worker.js`, `wrangler.toml` — сервер на Cloudflare (деплой через wrangler).
