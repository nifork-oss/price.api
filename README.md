# Кабинет мастера

Сайт лежит в корне репозитория, без папок.

## Страницы
- `index.html` — прайс и смета для заказчиков, правка прайса.
- `calc.html` — кабинет мастера (калькулятор, объекты, история, замер).
- `view.html` — счёт для заказчика по ссылке.

## Части кабинета мастера (`calc.html`)
- `calc.css` — оформление.
- `calc-app.js` — основа: вход, калькулятор, счета, история, объекты, PDF.
- `calc-measure.js` — замер и расчёты (стены, проёмы, откосы, потолок).
- `calc-rooms.js` — помещения объекта и выбор работ.
- `calc-ruler.js` — рулетка, чертёж, развёртки стен, окна и двери.
- `calc-molding.js` — лепнина: карнизы, плинтус, молдинги на потолке и стенах.
- `calc-tile.js` — плитка: на стенах и на полу, размер, шов, раскладка, запас, упаковки.
- `calc-mask.js` — укрывка: окна, двери, мебель, пол, потолок, готовые стены; теневые профили; периметр примыкания без двойного счёта общих участков, в счёт по видам; план и развёртки.
- `calc-plan.js` — обмерный план в PDF.
- `calc-flat.js` — план квартиры целиком: помещения от нейросети углами в общей системе координат → обычные замеры комнат + место на плане; экран «План квартиры» у объекта.
- `calc-plangeo.js` — распознанный план из точек картинки в мм: края помещений подгоняются по стенам на картинке, масштаб — по подписанным размерам, размеры помещений — точно по подписям, двери пар — напротив; картинка — подложкой под план квартиры.
- `calc-planfile.js` — план объекта в файле .json: сохранить на устройство, загрузить из файла или вставить текст (свой формат с замерами целиком или углы в мм, как отвечает нейросеть); дальше — тот же экран проверки, что после распознавания.
- `calc-import.js` — подложка и распознавание плана.
- `calc-assistant.js` — «Помощник по счёту»: чат с нейросетью (через воркер, ключ ANTHROPIC_API_KEY), подбирает работы из прайса, объём по поверхностям считает калькулятор.
- `calc-paid.js` — платные функции (распознавание и помощник) с баланса мастера в рублях: запрос на пополнение, у админа — зачисление, цены за токены, расход.
- `calc-aichats.js` — история чатов помощника и распознавания плана (хранится в браузере, IndexedDB).
- `calc-apikeys.js` — API-ключи мастера в профиле (ключ с инструкцией для ИИ-агента или своего сайта) и замеры от агента у объекта: проверить и добавить.
- `calc-extras.js` — оповещение «Сайт обновлён» и мелочи.

**Важно:** при обновлении любой части заливайте вместе с ней и `calc.html` —
в нём стоят метки версий частей, по ним телефоны понимают, что пора обновиться.

## Остальное
- `sw.js`, `manifest.json`, `icon-*.png` — установка как приложения.
- `worker.js`, `wrangler.toml` — сервер на Cloudflare (деплой через wrangler).

## API по ключу
Мастер создаёт ключ в «Профиле» → «API-ключи и ИИ-агент». Запросы — с заголовком `X-API-Key`,
адрес — воркер (`https://price-api.nifork.workers.dev/api/v1/...`). Полная инструкция (её же копирует кнопка
«Скопировать для ИИ-агента») — `GET /api/v1/help`. Коротко: `GET /services` (прайс), `GET|POST /objects`,
`POST /objects/<id>/plans` (замеры — ждут проверки мастером), `GET|POST /estimates`, `GET /estimates/<id>`.
На сервере хранится только SHA-256 ключа; изменения — не больше 10 в минуту на ключ.

## Сервер через VPS
У части провайдеров в России `*.workers.dev` заблокирован, поэтому страницы ходят к воркеру через nginx
на VPS: `https://moysite.duckdns.org/price-api/…` → `https://price-api.nifork.workers.dev/…`.
Кусок конфига nginx (в `server` для moysite.duckdns.org):

```nginx
location /price-api/ {
    proxy_pass https://price-api.nifork.workers.dev/;
    proxy_ssl_server_name on;
    proxy_set_header Host price-api.nifork.workers.dev;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_buffering off;          # ответы нейросети идут потоком
    proxy_read_timeout 300s;
    client_max_body_size 25m;     # фото отчётов и планы
}
```

Воркер верит `X-Real-IP` только от адреса VPS (`TRUSTED_PROXY_IPS` в `worker.js`) — для ограничения попыток входа.

## Проверки
- `tests/` — автопроверки расчётов замера (площади, чертёж, подправка плана, подиумы и короба) и помощника.
  Запуск из корня: `node --test`. На GitHub они идут сами при каждом PR.
